# order.perfect.digital

Perfect Digital's online ordering pages, served by GitHub Pages at https://order.perfect.digital.

- `index.html` - the Order online page (photo prints and personalised cards)
- `prints/` - the photo prints page. Orders go to the "Photo orders" Google Apps Script web app.
- `cards/` - the card maker. Orders and payments go to the "Card orders" Google Apps Script web app (Stripe Checkout).

Both pages are single HTML files. The working copies and the scripts are described in the Business project notes in Claude.
